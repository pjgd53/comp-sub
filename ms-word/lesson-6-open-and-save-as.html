📂 Opening, Editing, and Save As

How to find your saved work, keep editing it, and make a copy with a new name.

📂 Opening a Saved Document

In Lesson 2 you learned how to save your work. Now let's get it back! Click the File tab, then click Open — or press Ctrl + O. Word shows a list of Recent documents you worked on. Click your file's name to open it.

Can't see your file in the list? Click Browse and look inside the Documents folder.

✏️ Editing Your Work

Once the document is open, you can keep working on it like before — add new sentences, fix mistakes, or change the formatting. When you're done, press Ctrl + S to save your changes.

💾 Save vs. Save As

💾 Save Ctrl + S

Saves your changes into the same file. The old version is replaced with the new one.

📑 Save As F12

Saves a new copy with a different name or in a different folder. The original file stays the same.

Use Save As when you want to keep the first version safe — for example, saving "My Story" as "My Story - Final" before making big changes. Click File › Save As, type the new name, and click Save.

Good File Names Give files short names that tell you what’s inside, like "Grade 5 - Juan - Poem". Names like "Document1" or "asdf" are hard to find later!
Try It! Open the document you saved in Lesson 2. Add one new sentence, then use Save As to save it with a new name. Now open File › Open — can you see both files in the Recent list?

✅ What You Learned

  • File › Open or Ctrl + O opens a document you saved before.
  • The Recent list shows files you worked on lately; Browse lets you look in folders.
  • Save (Ctrl + S) updates the same file. Save As (F12) makes a new copy.
  • Short, clear file names make your work easy to find.
